🦞 AI 收藏夹 · 边界清单 v1

2026-05-21 · 哪些能进 / 哪些不能 / 每类边界细节
总原则：AI 收藏夹 ≠ 云盘
存"用户精选的知识资产"，不存"用户全部文件"。
采用混合存储策略：能在原网站找回的 → 引用；用户预期能找回的 → 存本体（文档 / 截图 / AI 对话）。
核心价值 = 找回它 + AI 能用它，不是替用户保管所有文件。

✅ 支持收藏的 8 大类型

📚 1 · 网页书签（URL） 支持
存什么URL + 标题 + 抽取正文 + 摘要（≤ 200 字） + 向量 + 缩略图 上限单条摘要 ≤ 200 字 / 总数 ≤ 50,000 条 特殊与书签管理器双向同步，三位一体
🖼️ 2 · 图片（含截图） 支持
存什么本地图 / 截图：存本体；网页图：存 URL + 自动备份缩略图（防原图失效）。统一加：OCR + 视觉描述 + 向量 上限单图 ≤ 10MB（截图 ≤ 5MB）/ 格式 jpg / png / webp / gif / bmp / heic 自动转 jpg 不支持> 10MB 大图（提示压缩）/ 加密相册图 / DRM 加密屏幕（如付费视频画面被锁） 特殊截图自动识别来源页 URL（如有）+ OCR / 网页原图失效（404）时降级展示缩略图，标"原图已失效"
🎬 3 · 视频 支持
存什么视频 URL + 封面 + 字幕文本（如有）+ 关键帧描述 + 向量 上限不存视频本体（学 NotebookLM 处理 YouTube） 不支持本地视频文件（>50MB 不收，引导走云盘）/ DRM 加密 / 直播流 特殊支持时间戳锚点（"看到 03:25 这段"）
📄 4 · 文档（PDF / Word / PPT / Excel / Markdown / TXT） 支持
存什么文件本体（云端副本） + 文件名 + 解析文本（≤ 200 页）+ 向量 + 缩略图 上限单文件 ≤ 50MB / 总文档数 ≤ 500 / 单用户文档总容量 ≤ 5GB 不支持加密 PDF（提示输入密码或跳过）/ 嵌套压缩包 特殊跨设备同步可见，原文件被删 AI 收藏夹仍保留副本；超 50MB 引导走小云盘
✂️ 5 · 摘录（划词文字） 支持
存什么选中文字 + 来源 URL + 抓取时间 + 向量 上限单条 ≤ 5000 字 不支持跨网页拼接的摘录（仅单页内） 特殊保留原文锚点，回访时高亮原位置
</> 6 · 代码片段 支持
存什么代码本体 + 语言标签 + 来源 URL（如有）+ 用户标注 + 向量 上限单条 ≤ 50K 字符 / 总数 ≤ 1000 条 不支持整个仓库压缩包（见红线）/ 含密钥的代码（识别到 token/key 时提醒用户脱敏） 特殊支持 30+ 语言高亮 / 一键复制 / 元宝可问"这段代码做什么" / 可关联到来源网页
🎧 7 · 音频 支持
存什么音频本体（云端必存） + ASR 自动转录文本 + 时间戳锚点 + 向量 上限单音频 ≤ 50MB（约 1 小时常规码率）/ 总数 ≤ 100 条 不支持DRM 加密音频（如 Apple Music）/ 直播流（非沉淀语义） 特殊ASR 转录后文字可搜可问 / 支持时间戳跳转 / 元宝可基于转录内容问答
🤖 8 · AI 对话 / Prompt 支持 · 核心差异化
存什么完整对话文字（QA pair）+ AI 引用的 URL 列表 + 工具调用记录 + 向量 / Prompt 模板 上限单对话 ≤ 100K token / 嵌套图 ≤ 5 张 / 嵌套文档 ≤ 3 个 / 总对话数 ≤ 500 / Prompt 库 ≤ 200 条 不支持第三方 AI 产品（ChatGPT / Claude）的对话——只支持元宝 / 单嵌套文件 > 50MB（引导走小云盘） 特殊① 沉淀 = 永久副本，与元宝侧完全独立（元宝删原对话 / 改对话 / 分享失效 → AI 收藏夹副本不受影响）
② 嵌套资产自动分流：对话里的图片自动入「图片」Tab、文档入「文档」Tab、AI 生成 PPT 入「文档」Tab，互相关联标"来自 X 月 X 日的元宝对话"
③ 主对话本身仍保留在「AI 对话」Tab，引用链接指向各 Tab 的嵌套资产

❌ 明确不收的 6 类（红线）

大文件视频本体（> 50MB） 学 NotebookLM，非云盘业务，引导走小云盘
可执行文件（exe / dmg / apk） 安全风险 + 无 AI 价值
加密压缩包 内容不可解析 = AI 用不了
代码仓库整体（.git / 大型仓库压缩包） 仓库整体非"知识资产"。单独代码片段 → 走「代码」Tab 收藏
其他 AI 产品的对话（ChatGPT / Claude） 数据合规风险 + 元宝场景内闭环
直播流 / 实时音视频 非"沉淀"语义

🎯 边界设计的 3 条核心原则

1 AI 收藏夹 ≠ 云盘

存"用户精选的知识资产"，不是"用户全部文件"。和小云盘业务共生不重叠。

2 混合存储策略

能在原网站找回的 → 引用（网页/视频/摘录）；用户预期能找回的 → 存本体（文档/图片/截图/代码/音频/AI对话）。

3 找回 + AI 能用

每条资产入库自动生成摘要 + 标签 + 向量，统一被元宝 RAG 调用，做用户记忆库。

🤝 关键边界 · 与小云盘业务共生

⚠️ 最容易出问题的场景
用户拖一个 500MB 视频进 AI 收藏夹 → 用户期待存好 → 我们做不到（成本+合规）
✅ 解决方案
超过阈值时给清晰提示「文件过大，建议存到小云盘后再加入 AI 收藏夹」+ 一键跳转小云盘。
这是和小云盘业务划边界 + 共生的关键 hook，避免被误读为"又一个云盘"。
🚨 写进 PRD 的硬约束
AI 收藏夹采用混合存储：网页类轻量索引（KB 级）+ 文档/截图/代码/音频/AI对话存本体（受单文件 50MB 限制 + 单用户文档总容量 ≤ 5GB）。
单用户总占用控制在数百 MB 量级，远小于云盘业务（GB 级），定位不重叠。
🦞 一句话定调：云盘 = 存文件本体；AI 收藏夹 = 存"线索 + 语义索引"。
云盘解决"存东西"，AI 收藏夹解决"找东西 + 用东西"。
