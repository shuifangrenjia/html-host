🦞 AI 收藏夹 · 边界清单 v1

2026-05-21 · 哪些能进 / 哪些不能 / 每类边界细节
总原则：存「线索 + 语义」/ 不存「文件本体」
用户的资产留在原处（网站 / 云盘 / 本地），AI 收藏夹只存 找回它 + AI 能用它 的能力。

✅ 支持收藏的 6 大类型

📚 1 · 网页书签（URL） 支持
存什么URL + 标题 + 抽取正文（≤ 50K 字）+ 向量 + 缩略图 上限单条正文 ≤ 50K 字（超过截断）/ 总数 ≤ 1 万条 不支持需登录态才能访问的内部网页（抽取失败时仅存 URL+标题） 特殊与书签管理器双向同步，三位一体
🖼️ 2 · 图片 支持
存什么网页图：URL 引用 + OCR + 视觉描述 + 向量；本地图：≤2MB 直接上云存副本 上限单图 ≤ 10MB / 格式 jpg/png/webp/gif/bmp / heic 自动转 jpg 不支持> 10MB 大图（提示压缩）/ 动图 GIF 仅存首帧描述 / 加密相册图片 特殊网页图优先存 URL 引用，本地拖入存副本
🎬 3 · 视频 支持
存什么视频 URL + 封面 + 字幕文本（如有）+ 关键帧描述 + 向量 上限不存视频本体（学 NotebookLM 处理 YouTube） 不支持本地视频文件（>50MB 不收，引导走云盘）/ DRM 加密 / 直播流 特殊支持时间戳锚点（"看到 03:25 这段"）
📄 4 · 文档（PDF / Word / PPT / Excel / Markdown / TXT） 支持
存什么文件名 + 解析后的文本（≤ 200 页）+ 向量 + 缩略图 上限单文件 ≤ 50MB（参考 NotebookLM 单 Source 上限）/ 总文档数 ≤ 500 不支持加密 PDF（提示输入密码或跳过）/ 扫描件无 OCR 时仅存图（标"图像版"）/ 嵌套压缩包 特殊文件本体不存（引用本地路径或来源 URL），原文件被删时显示"已不存在"
✂️ 5 · 网页摘录（划词 / 截图） 支持
存什么选中文字 / 截图 + 上下文 50 字 + 来源 URL + 抓取时间 + 向量 上限单条文字 ≤ 5000 字 / 截图 ≤ 5MB 不支持跨网页拼接的摘录（只能单页内）/ 受版权保护页面整页拷贝（高敏感站点限缩） 特殊保留原文锚点，回访时高亮原位置
🤖 6 · AI 对话 / Prompt 支持 · 核心差异化
存什么元宝对话完整记录（QA + 引用 Source）+ 向量 / Prompt 模板（标题+内容+变量） 上限单对话 ≤ 100K token / 用户 Prompt 库 ≤ 200 条 不支持第三方 AI 产品（ChatGPT / Claude）的对话——只支持元宝 特殊对话沉淀时自动关联当时引用的 Source 资产

❌ 明确不收的 7 类（红线）

大文件视频本体（> 50MB） 学 NotebookLM，非云盘业务，引导走小云盘
可执行文件（exe / dmg / apk） 安全风险 + 无 AI 价值
加密压缩包 内容不可解析 = AI 用不了
数据库 / 代码仓库整体（.db / .git） 工程文件不是"知识资产"
私密性极高内容（密码 / 身份证扫描件） 应走"私密空间"独立产品（1Password 模式）
其他 AI 产品的对话（ChatGPT / Claude） 数据合规风险 + 元宝场景内闭环
直播流 / 实时音视频 非"沉淀"语义

🎯 边界设计的 3 条核心原则

1 存"线索 + 语义"

不存"文件本体" → 区别于云盘 → 成本可控

2 网页类优先 URL 引用

用户原资产在原网站，我们只存"找回 + 用得上"的能力

3 本地文件用引用

不替用户保管原文件，原文件删了我们只留"曾经存过"的元数据

🤝 关键边界 · 与小云盘业务共生

⚠️ 最容易出问题的场景
用户拖一个 500MB 视频进 AI 收藏夹 → 用户期待存好 → 我们做不到（成本+合规）
✅ 解决方案
超过阈值时给清晰提示「文件过大，建议存到小云盘后再加入 AI 收藏夹」+ 一键跳转小云盘。
这是和小云盘业务划边界 + 共生的关键 hook，避免被误读为"又一个云盘"。
🚨 写进 PRD 的硬约束
AI 收藏夹的存储模型 = "metadata + text + vector"，不是 "file storage"。
单条资产体积约 ≤ 几 KB，1000 条 ≈ 几十 MB 索引（云端）→ 成本可控、和云盘业务无重叠。
🦞 一句话定调：云盘 = 存文件本体；AI 收藏夹 = 存"线索 + 语义索引"。
云盘解决"存东西"，AI 收藏夹解决"找东西 + 用东西"。
