AI 收藏夹 · 研发需求清单 v1

基于姝然交互稿（Claude-Design-Project 体验包）拆解 · @geoffreyyou 给研发对齐用
说明：本清单聚焦"做什么 + 关键约束 + 交互逻辑"，不写接口/代码细节。每条都按"用户视角的交互流"描述，研发可基于此定接口与实现方式。
红字=关键约束 / 边界规则；橙字=可决策点（待定/可调）。

1 · 浏览器外壳（顶部容器）
需求名称需求概述
收藏夹 Tab 入口浏览器顶部 tab 区固定入口"收藏夹"，黄色书签 favicon。点击切到收藏夹主页（默认 Tab）。该 Tab 默认开启，用户不可关闭（避免用户误关后找不到入口）。
地址栏「加入收藏」按钮地址栏右侧固定 ⭐ 按钮，点击 → 把当前网页加入 AI 收藏夹「书签 Tab」。已收藏的网页 ⭐ 高亮。
地址栏「抓取」按钮仅在当前页面是可抓取页面（非收藏夹自身）时显示。点击或长按 C 键触发抓取模式。"可抓取页面"由前端基于 URL/页面类型识别，待与研发确认识别规则。
元宝助手入口浏览器顶部右侧元宝助手按钮 → 唤起元宝。元宝可调用 AI 收藏夹的资产作为上下文（与「右侧 AI 面板」共享同一对话能力）。
书签栏浏览器顶部书签栏：「全部书签 / 主页快链 / 手机书签 / 用户文件夹」。与 AI 收藏夹「书签 Tab」共享同一份数据（增/删/改/拖拽实时双向同步）。
2 · 左侧栏（导航）
需求名称需求概述
全部展示用户所有已收藏内容（不分类型、不分文件夹），按时间倒序。右侧角标显示总数（如 326）。
最近添加展示用户近 30 天收藏内容，上限 50 条，按时间倒序。
书签收藏（树状）仅在用户点选顶部「书签」类型 Chip 时显示。3 级树状结构：
· 一级「书签收藏」（可整体折叠）
· 二级「普通书签 / 常用书签」（可独立展开折叠，文件夹图标）
· 三级具体文件夹（如：科技资讯 / 设计资源 / 生活 / 文献资源 / 常用视频网站 / 直达快链 / 腾讯）
三级树与浏览器原书签管理器完全套壳同步。
用户标签区展示用户的所有 AI 标签 + 用户手动标签（混合展示，是否区分待定）。每个标签右侧显示该标签下资产数量。点击进入该标签筛选态。顶部"+"按钮支持新建标签。
导航项 · 选中态点击任意导航项 → 主内容区按该范围筛选。同时切换时清空当前选中条目（详情面板）。
导航项 · 拖拽接收支持把主内容区的卡片拖拽到左侧文件夹/标签上完成移动/打标。系统类（全部/最近添加）不支持拖入。
3 · 顶部操作栏（搜索 / 视图 / 排序 / 面板切换）
需求名称需求概述
搜索框支持自然语言搜索（例如"关于设计哲学的文章"）。匹配字段：标题 / 描述 / 摘要 / 来源 / 用户标签 / AI 标签 / 摘录原文。Cmd+K 全局快捷键聚焦搜索。回车后若有内容 → 同时唤起右侧 AI 面板，把搜索词作为对话起点。
视图切换 · 瀑布流默认视图。多列卡片瀑布流（默认 4 列，紧凑模式 5 列；详情面板打开时减 1 列）。
视图切换 · 按来源按 source.name 分组，每组显示来源头像 + 数量 + 时间，组内卡片横向排列。组按数量倒序。
视图偏好持久化用户最后选择的视图 / 紧凑度 / 强调色 / 是否显示 AI 建议条 等偏好账号级保存，跨设备一致。
排序菜单下拉菜单 2 个选项：
· 按时间（默认，最新添加优先）
· 按类型（同类聚集，类型顺序：图片 → 视频 → 网页 → AI 对话 → 摘录 → 代码 → 文件 → 音频；同类型内仍按时间倒序）
右侧面板切换两个独立按钮控制右侧面板：
· ✨ AI 对话面板（与收藏对话）
· ▮ 详情面板（条目详情）
同一时刻最多打开一个，切换时另一个自动关闭。
4 · 主内容区（瀑布流默认态）
需求名称需求概述
Hero 标题区页面顶部显示当前作用域名称（如"全部 / 最近添加 / 京都旅行 / #设计 标签"）+ 该范围的总条数（"共 X 条收藏"）。可在设置面板关闭。
类型 Chip 筛选条Hero 区右侧横向 Chip 行，8 个类型 + 全部：全部 / 书签 / 图片 / 视频 / 文档 / AI 对话 / 摘录 / 代码 / 音频。点击切换类型筛选。仅"书签"Chip 选中时，左侧栏才显示书签收藏树状结构。
AI 建议条无搜索词且当前作用域有内容时显示。包含 1 行标题（动态生成，如"让 AI 重新整理京都旅行这 12 条收藏"）+ 3 个推荐 prompt 按钮。标题 / prompt 都根据当前 chip / 文件夹 / 标签 动态生成（每个文件夹各有 3 条贴切 prompt，详见数据约定）。点击 prompt 直接进入右侧 AI 面板并自动发送。
瀑布流卡片区所有筛选后的资产以卡片形式渲染。卡片宽度自适应列数，高度根据内容（图片宽高比 / 文字行数）。滚动加载 / 列高度均衡布局。
空态当前筛选无内容时显示空态提示文案（"该范围暂无收藏" + 引导操作）。
5 · 主内容区（按来源分组态）
需求名称需求概述
来源分组头每组顶部显示：来源色块头像（首字母）+ 来源名称 + 该组条数 + 最新一条时间 + ⋯ 操作按钮。
来源组内排列同一来源的卡片在该组下横向排列（不再瀑布流）。
分组顺序按各组条数倒序（最多的来源排最前）。
6 · 资产卡片（通用结构 + 8 类差异化）
需求名称需求概述
通用结构每张卡片包含：类型徽章 + 主体内容（图/标题/摘录文字/对话首条等）+ 标题 + 描述 + 标签行 + 元信息（来源 favicon + 来源名 + 时间）。所有卡片可拖拽。
类型徽章卡片左上角显示：图片/视频/书签/文档/AI 对话/代码/摘录/音频 8 类徽章（图标+文字）。
快捷操作浮层hover 卡片时右上角浮出 4 个按钮：⭐ 收藏（已收藏=填充）/ ✨ 问 AI / 🔗 分享 / 🗑 删除。多选模式下隐藏快捷操作。
标签行卡片底部显示标签：用户标签（深色） + AI 推荐标签（带 ✨ 图标，浅色，含"采纳"+按钮）。仅当用户没有手动打过标签时才展示 AI 推荐；用户采纳一个 AI 标签 → 该标签变成用户标签（深色），剩余 AI 标签继续展示直到全部被采纳。最多展示 4 个，超出折叠。
单击卡片单选模式下：单击 → 打开右侧详情面板，定位到该条。再次点击同一条 → 不变；点击其他条 → 切换详情。
多选模式触发通过 hover 卡片复选框/Shift+点击 进入多选。选中第一条后底部出现批量操作栏。
图片卡主体为图片（保留原图宽高比）。无图时显示骨架占位。
视频卡主体为视频封面图 + 时长徽章 + 播放按钮 hover 态。仅 B 站/YouTube 等支持源能拿到封面，其他视频网站仅显示 URL + 视频标题（依赖网页文本抽取）。
书签卡（网页）主体为网页 OG 图（如有）+ 标题 + 摘要（≤200 字）。无 OG 图时显示纯文本卡。
文档卡主体为文档缩略图 + 文件名 + 页数/大小信息（如 PDF · 12 页 · 2.4MB）。
AI 对话卡主体为对话第一轮 QA 摘要 + ✨ 徽章。点击 → 详情面板展示完整对话。
代码卡主体为代码片段（带语法高亮）+ 语言标签。
摘录卡主体为引号样式包裹的摘录文字，浅黄底渐变。下方显示来源页面标题 + URL。
音频卡主体为音频封面 + 标题 + 时长 + 播放按钮。
7 · 多选批量操作栏
需求名称需求概述
浮动操作栏选中 ≥1 条时浮出主内容区底部。显示"已选 X 项"+ 5 个操作按钮 + ✕ 退出多选。
加星把选中所有条目加入"已加星"集合。已加星与"全部/最近添加"等系统集合并列展示，左侧栏是否独立 Tab 待定。
移动到…下拉菜单选择一个用户文件夹 → 批量更新归属。系统类（all / recent / ai）禁止移入。
添加标签下拉/输入框选已有标签或新建标签 → 批量加上。
问 AI把选中条目作为上下文一次性发给元宝。右侧 AI 面板自动打开，AI 收到 N 条上下文。
删除把选中条目删除。需走 30 天回收站机制（与"已清理书签"文件夹一致），用户可在回收站恢复。
8 · 右侧详情面板
需求名称需求概述
面板头展示当前条目类型徽章 + "类型 · 详情" 标题。右侧 3 个按钮：⛶ 全屏 / ✕ 关闭。
书签详情显示标题（可点击跳转原网址）+ 来源 favicon + 时间 + 标签行 + 操作按钮（与这条对话 / 收藏 / 分享）+ 完整正文（小标题 + 段落结构）。无正文时由前端基于 desc/title 生成 fallback 长文展示，需由后端预生成或预存正文摘要+段落结构。
图片详情显示原图 + 标题 + 来源 + 时间 + 标签 + 操作按钮 + 主题推荐区（最多 6 个 tag 主题代表图，每个图叠加白色加粗主题名）。点击主题图 → 进入"主题模式"。
非书签/非图片详情摘录/AI 对话/文件/代码/音频的详情：差异化展示主体（引号摘录/对话气泡/文件信息/代码块/音频播放器）+ 摘要 + 标签 + 操作按钮 + 「你可能感兴趣的内容」推荐区。
关联推荐区仅推荐用户已收藏的资产（不引入全网新内容，避免变 feed 流）。
推荐挑选规则（按优先级）：
① 共享标签 > ② 同文件夹 > ③ 全局兜底
最多 6 条。是否需要"关闭/折叠推荐"开关待定。
主题模式（仅图片详情）点击主题代表图 → 切换为"推荐 · {主题}"模式。展示该 tag 下所有其他图片的瀑布流。顶部"← 返回"按钮 + ⛶ 全屏 + ✕ 关闭 + 黑色"聊聊「主题」"按钮（点击 → 切到 AI 面板，自动发送 prompt）。
删除主题用户可"删除"某个主题不再推荐（局部记住，不影响其他详情）。
放大态⛶ 按钮触发全屏 overlay：左侧大图 / 右侧标题 + 来源 + 时间 + 描述 + 3 个操作（与这条对话 / 分享 / 打开原页）。点击 overlay 背景或 ✕ 关闭。
空态未选中条目时显示"选择一条收藏以查看详情"提示。
9 · 右侧 AI 对话面板
需求名称需求概述
面板头显示"与收藏对话"标题 + 当前上下文范围（"基于 N 条收藏" 或 "基于 1 条上下文"）+ ✕ 关闭。
空态欢迎语无对话且无上下文条目时，展示 1 段欢迎语 + 推荐 prompt 列表（来自全局 AI_PROMPTS）。
上下文模式从卡片"问 AI"或多选"问 AI"进入时，AI 自动打第一句招呼"我已经看到你保存的「{标题}」..."，绑定该条/该集合作为上下文。
对话气泡用户消息 = 强调色实底；AI 消息 = 白底带边框。AI 回复内容由元宝助手基于"用户提问 + 上下文资产"生成。
引用 chip（cite）AI 回复底部展示"引用了 N 条收藏"chip 列表。每个 chip 显示标题 + 来源。点击 chip → 切到详情面板，定位到该条。
输入框底部输入框（"问问你的收藏库吧…"）+ 发送按钮。回车发送 / Shift+回车换行。
外部触发对话支持 AI 建议条 / 主题模式按钮 等外部入口预填一段 prompt 自动发送。
输入中提示AI 回复期间展示三点 loading 动画。
10 · 抓取模式 - 图片网站类（Pinterest）
需求名称需求概述
触发方式2 种触发：
· 点击地址栏「抓取」按钮 → 进入
· 长按 C 键 → 进入；松开 C → 退出（除非已选中至少 1 项）
正在输入文本时不响应快捷键。
蒙层页面叠半透明黑色蒙层 + 边缘蒂芙尼蓝→紫色渐变光晕。
元素 hover 高亮鼠标 hover 网页元素 → 在蒙层上"挖洞"高亮该元素 + 描边。
单选单击元素 = 选中。再次单击 = 取消。
多选⌘ + 点击 = 多选。多选元素自动连成一片采集区域（包围盒）。
采集工具条选中后元素附近浮出工具条：
· 左侧：标签下拉（默认显示 LocalStorage 上次选择，记忆机制）
· 右侧（仅 picked 时）：⭐ 收藏按钮
多选数量徽章多选时左上角徽章显示数量"X 张/X 条"（图片显"张"，其他显"条"）。
收藏入库点击 ⭐ → 把选中元素入库到当前选择的标签/文件夹。Toast 提示"已收藏 X 张到「{文件夹}」"。抓取模式自动退出 + 清空选中。
退出方式3 种退出：
· ESC
· 收藏完成自动退出
· 关闭按钮
有选中项时松开 C 键不退出，必须主动操作。
提示语蒙层顶部固定提示"长按C 抓取 · 单击选中 · ⌘+点击 多选 · ESC 退出"。
11 · 抓取模式 - 文章网页类（资讯/博客）
需求名称需求概述
页面元素分块前端识别页面正文块：标题 / 段落 / 图片 / 小标题 4 种粒度。识别规则待和工程对（基于 DOM 结构 / 语义标签）。
分块抓取同 Pinterest 触发/单选/多选机制。可单独抓 1 个段落、1 个标题、1 张图，或多块组合。
类型自动判定根据选中块类型自动判定收藏类型：
· 仅含文字（段落/标题）→ 入库为「摘录」
· 含至少 1 张图 → 入库为「图片」（同时保留原文上下文）
Toast 提示对应类型："已保存 1 个段落到「{文件夹}」"
原文锚点摘录入库时自动记录来源 URL + 段落锚点，用户回访详情时可定位到原文位置。

13 · 通用交互
需求名称需求概述
拖拽到文件夹主内容区任意卡片可拖到左侧栏的用户文件夹/标签。拖入时左侧目标项高亮反馈。释放 → 移动归属 + Toast 提示"已移动 X 条到「{文件夹}」"。
· 单条拖拽：仅移动该条
· 多选状态下拖拽其中一条：移动选中全部
拖拽到加星拖到"已加星"系统类 → 加星全部（不移动归属）。
Toast 提示所有写操作（删除/移动/加星/收藏入库）1.8 秒消失的 Toast 反馈。同时只显示一个，新 Toast 覆盖旧的。
删除回收所有删除走 30 天回收机制（与死链清理"待清理书签"文件夹一致）：先进回收站不直接物理删，30 天后自动清空，用户可在回收站恢复。
键盘快捷键· Cmd+K 聚焦搜索框
· 长按 C 进入抓取模式（仅可抓取页面）
· ESC 退出抓取模式 / 关闭 overlay
· Shift+点击 多选
· Cmd+点击 多选（抓取模式）
空态/错误态所有数据加载失败 / 抽取失败时显示降级文案 + 重试按钮，不阻塞主流程。
⚠️ 待决策点（需要 PM/工程一起拍）
点决策内容
D1 · 视频源支持PC 端非 B 站/YouTube 的视频网站，是否走"网址 + 视频标题"兜底（仅文本抽取）？还是一期不收？
D2 · 抓取页面识别"哪些页面支持地址栏抓取按钮"——基于 URL 模式 / DOM 结构 / 用户白名单？
D3 · 关联推荐开关是否给关联推荐增加"折叠/关闭"开关？姝然方案默认常驻。
D4 · 双导航边界左侧栏"书签收藏树状"与"用户标签区"在用户认知上的区分（一对一文件夹 vs 一对多标签）—— 需视觉/交互上明确区分。
D5 · 已加星位置"已加星"作为系统集合，是否在左侧栏独立 Tab 展示？
D6 · 文档卡承载文件 Tab 在体验稿中显示 PDF/Word/PPT 等。是否一期就支持文档本体云端存储（≤50MB）？
