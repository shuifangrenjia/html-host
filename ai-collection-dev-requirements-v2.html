需求 01

抓取能力建设

重点 / 核心差异化
用户通过"抓取模式"进入网页元素粒度的精细化收藏 —— 把页面拆解成可识别的内容块（图片 / 视频 / 段落 / 标题等），用户可单选 / 多选 / 框选后一键入库。覆盖两类典型场景：① Pinterest / 小红书等图片瀑布流类网站；② 资讯文章 / 博客 / 知乎专栏类长文。
功能点逻辑说明
入口 1 · 地址栏「抓取」按钮 用户在任意网页地址栏右侧看到「抓取」按钮（图标 + 文字），点击 → 触发当前页进入抓取模式。仅对网页生效，特殊页面（如设置页 / 浏览器内置页）不展示该按钮。
入口 2 · 元宝助手内入口 元宝助手对话场景下，用户提问"帮我整理这个网页里的图" 类需求时，元宝可主动调起当前页的抓取模式（与上面同一套交互）。
入口 3 · 快捷键 用户在网页任意位置 长按 C 键 ≥ 0.3s → 直接进入抓取模式。松开即退出抓取模式（轻量瞬时模式）。
抓取模式触发后的页面表现 原网页内容上方覆盖一层半透明蒙层，挖洞展示可抓取的内容块（图、视频、段落、标题等）。蒙层顶部显示模式状态条（"已选 X 项 / 完成 / 取消"）。
页面内容块识别规则 系统自动识别网页内可抓取的"内容块" —— D2 待决策：识别哪些粒度？目前体验包里识别图片 / 视频 / 段落 / 标题 / 卡片整体共 5 种；不可抓取区域（导航 / 广告 / 页脚等）不识别。
单选交互 用户鼠标 hover 任一可抓取块 → 挖洞高亮该块 + 显示"+ 收藏此项"小按钮；点击 → 该块进入"已选"状态（角标显示编号 1）。
多选交互 支持连续点击多块累计选中（每选中一块编号 +1）；支持框选（鼠标拖拽划定矩形区域，区域内的可抓取块全部进入已选）。
退选 / 全选 / 反选 已选中的块再次点击 → 退选（角标消失，编号重排）；蒙层顶部状态条提供「全选」「反选」「清空」按钮。
顶部工具条 抓取模式下页面顶部固定一条工具栏，包含：① 已选数量；② 「收藏选中」主按钮；③ 「全选 / 反选 / 清空」次按钮；④ 「ESC 退出」提示；⑤ 切换"图片优先 / 文字优先"识别模式。
"收藏选中"动作 用户点「收藏选中」 → 对所选每一块执行收藏 → 各块按类型自动分流到对应 Tab（图片 → 图片 Tab / 段落 → 摘录 Tab / 视频 → 视频 Tab）；每块自动带上来源 URL + 抓取时间 + 网页标题。
退出抓取模式 三种退出方式：① ESC 键；② 工具栏「退出」按钮；③ 收藏完成后 1.5s 自动退出。退出时蒙层渐隐消失，回到正常网页。
成功提示 收藏完成后右下角 toast："已收藏 X 项到 AI 收藏夹"，附「查看」按钮（点击跳转到 AI 收藏夹相应 Tab）。Toast 3s 自动消失。
失败兜底 ① 单块收藏失败 → toast"X 项收藏失败，已重试"，自动重试 1 次；② 全部失败 → 红色 toast"网络异常，请稍后再试"，已选状态保留 30s 内可点重试；③ 用户主动放弃 → 不入库。
边界规则 ① 单次抓取上限 50 项，超过提示精选；② 跨页面拼接抓取不支持（单页内）；③ 抓取模式启动时若网页加载未完成 → 提示"等页面加载完再试"。
D2 待决策：① 哪些 URL / 站点支持抓取？是否所有网页都支持，还是先锚定 Pinterest / 小红书 / 知乎 / B 站等核心站点？② 不支持的页面是否隐藏「抓取」按钮，还是按钮置灰？
需求 02

快速收藏能力

高频入口
用户在不进入抓取模式的常规浏览状态下，能用最低成本快速收藏当前页 / 网页元素 / 选中文字 / 拖拽内容到 AI 收藏夹。覆盖整页收藏 + 局部收藏 + 拖拽收藏三类。
功能点逻辑说明
地址栏星标收藏（整页） 用户点击地址栏 ⭐ 按钮 → 当前页作为网页书签入库（类型 = 网页书签）→ 弹出小确认气泡，可改名 / 选标签 / 选文件夹。与浏览器原生书签管理器双向同步（同一份数据）。
Ctrl+D / Cmd+D 快捷键 等同地址栏星标点击，触发整页收藏 + 弹气泡。
右键菜单 · 网页元素 用户在网页内右键图片 / 视频 / 链接，菜单中显示"收藏到 AI 收藏夹" → 单击直接收藏，对应类型自动入库（图 → 图片 Tab / 视频 → 视频 Tab / 链接 → 网页书签）。
划词收藏 用户选中网页正文文字 → 选区附近浮起小工具栏 → 点击「收藏摘录」 → 摘录入摘录 Tab，自动带来源 URL + 选区上下文锚点。
拖拽收藏 ① 外部拖入：从桌面 / Finder 拖文件进 AI 收藏夹页面 → 自动分流到对应 Tab（pdf → 文档 / jpg → 图片 / mp4 → 视频）；② 页内拖到悬浮球：拖文字 / 图 / 链到右下角悬浮球 → 等同收藏。
悬浮球唤起 浏览器内右下角常驻悬浮球；快捷键 Ctrl+Space / Cmd+Enter 唤起一个轻量收藏面板（搜索 + 最近 5 条）。设置项可调位置 / 是否常驻。
收藏后反馈 所有快速收藏动作完成后，右下角统一 toast："已收藏 → 查看"，3s 自动消失，可点击跳转。
重复收藏处理 同一 URL / 同一文件已存在 → toast 提示"已存在收藏夹中"，不重复入库；用户可点 toast 跳转到原条目。
需求 03

AI 收藏夹工作台主界面

主阵地
AI 收藏夹的主界面 = 三栏工作台：左侧导航 / 中间内容流 / 右侧详情或 AI 面板。覆盖导航分类 / 视图切换 / 筛选排序 / 搜索四大基础能力。
功能点逻辑说明
主入口 ① 浏览器顶部固定 Tab 入口"AI 收藏夹"；② 新标签页快捷入口；③ 浏览器侧边栏入口。
左侧栏 · 全部 展示用户所有资产（不分类型，按时间倒序）。默认选中态。
左侧栏 · 最近添加 展示用户近 30 天收藏内容（上限 50 条），按收藏时间倒序。
左侧栏 · 书签收藏树 完全套壳现有书签管理器：树状结构 + 文件夹 + 拖拽 + 新建文件夹全部保留。「AI 收藏夹书签 Tab」、「浏览器顶部书签栏」、「旧书签管理器」三位一体，同一份数据。
左侧栏 · 标签区 显示 AI 自动打标 + 用户手动标签（如 #工作 #学习）。点击标签 → 中间内容区按该标签筛选。与"书签收藏树"分两个区域并列。
左侧栏 · 折叠 左侧栏顶部一个折叠按钮，可收起左侧栏 → 主内容区扩大铺满。再点展开。偏好持久化。
顶部栏 · 全局搜索 搜索框置顶，支持全模态搜索（同一关键词同时搜 8 类资产），结果按 Tab 分组展示，向量搜索 + 关键词搜索结合。
顶部栏 · 视图切换 两种视图：① 瀑布流（默认）—— 按收藏时间倒序混排；② 按来源 —— 按域名 / 站点分组堆叠。用户上次选择会被记住（账号级持久化）。
顶部栏 · 排序 下拉提供：最近收藏 / 最近访问 / 最常打开 / 类型分组。默认"最近收藏"。
顶部栏 · Tab 筛选 Chip 顶部一行 Chip：全部 / 网页 / 图片 / 视频 / 文档 / 摘录 / 代码 / 音频 / AI 对话。点击单个 Chip → 中间内容区筛选该类型；可多选（Ctrl + 点击）。
顶部栏 · 右侧面板切换 顶部栏右侧两个图标：「详情」「AI 助手」。默认隐藏右侧面板；点击对应图标 → 右侧滑出面板（详情 / AI 助手二选一）。
主内容区 · 瀑布流 多列卡片瀑布流（响应式 3-5 列），按选中的导航 / 筛选条件渲染对应资产。无限滚动加载。
主内容区 · 按来源视图 同一来源（如 zhihu.com / xiaohongshu.com）的资产堆叠成"来源卡组"，点击展开看该来源下全部资产。
AI 建议条（顶部 Hero） 主内容区顶部一条AI 建议横幅，展示给用户的智能建议（如"你最近收藏了 12 条 AI 相关文章，要不要让我帮你整理成专题？"），可点采纳 / 关闭。D3 待决策：是否做开关支持关闭。
需求 04

资产卡片体系（8 类）

通用 + 特殊
AI 收藏夹的"原子" = 资产卡片。8 类资产共享通用卡片结构，但每类有自己的特殊呈现和操作。
功能点逻辑说明
通用卡片结构 每张卡片都包含：① 类型徽章（左上角标识 8 类）；② 标题；③ 摘要 / 缩略图；④ 来源（域名 / 文件名 / 元宝）；⑤ 收藏时间；⑥ AI 标签（可点）；⑦ 右上角"已加星"标记（如有）。
卡片快捷操作（hover 出现） hover 卡片右上角浮出 4 个小按钮：⭐ 加星 / 🤖 问 AI / ⋯ 更多 / □ 多选。
单击卡片 ① 默认 → 右侧滑出详情面板（不离开当前页）；② 双击 / 中键 → 在新标签页打开原始资源。
拖拽卡片 支持把卡片拖到左侧栏的书签文件夹或标签上，即批量改归属。
网页书签卡片 展示网页 favicon + 标题 + 200 字摘要 + 来源域名。点击 → 详情区显示网页正文摘要 + 关联推荐。
图片卡片 展示图片缩略图（瀑布流自适应高度）+ OCR 摘要标签。点击 → 详情区显示原图大图 + OCR 全文。
视频卡片 展示视频封面（B 站 / YouTube 抽帧；其他站点用 OG 图兜底）+ 视频标题（网页字段抽取） + 来源站点。点击 → 详情区显示字幕摘要 + 跳转原页。D1 待决策：B 站 / YouTube 之外是否走"URL+标题"兜底。
文档卡片 展示文档图标（按格式区分 pdf/word/ppt）+ 文件名 + 解析后的首段摘要。点击 → 详情区调用 QB 文档查看器内嵌打开。
摘录卡片 展示选中文字（最多 3 行 + ellipsis）+ 来源 URL favicon。点击 → 详情区显示完整摘录 + "回到原文位置"按钮（带锚点跳转）。
代码卡片 展示语言标签（如 Python / JS）+ 代码片段（前 6 行 + 高亮）+ 来源。点击 → 详情区显示完整代码 + 一键复制 + 一键问元宝"这段代码做什么"。
音频卡片 展示音频图标 + 时长 + ASR 转录的首句。点击 → 详情区显示完整 ASR 转录 + 时间戳跳转 + 音频播放器。
AI 对话卡片 展示元宝头像 + 对话标题（用户首句问题）+ 对话摘要。点击 → 详情区展开完整 QA + 引用 Source + "继续问元宝"按钮。
需求 05

多选与批量操作

效率工具
用户可对收藏夹内的多条资产执行批量动作：批量加星 / 批量打标 / 批量移动 / 批量删除 / 批量发给元宝。
功能点逻辑说明
进入多选模式 ① 卡片 hover 时点击右上角"□"图标；② 顶部栏点击"多选"按钮。一旦选中第一张卡片，所有卡片左上角自动出现 checkbox。
选择交互 ① 单击 checkbox 切换选中；② Shift + 点击 范围选择；③ Cmd/Ctrl + A 当前视图全选；④ ESC 退出多选。
底部批量操作栏 选中数量 ≥ 1 时，底部弹出固定操作栏，显示：① 已选 X 项；② 加星；③ 加标签；④ 移动到文件夹；⑤ 问 AI；⑥ 删除；⑦ 取消。
批量加星 所选项全部标星 / 全部取消星（按当前主选项状态切换）。
批量加标签 弹出小窗，可选已有标签或输入新标签 → 应用到所有选中项。
批量移动到文件夹 弹出文件夹树选择 → 应用到所有选中项（仅对网页书签生效，其他类型不参与）。
批量问 AI 选中资产作为 context 发送给元宝 → 右侧 AI 面板自动展开 + 上下文已绑定 → 用户输入问题（如"对比这 3 篇"/"汇总观点"）。
批量删除 二次确认弹窗"确认删除 X 项？"→ 删除后进入30 天回收站，顶部 toast 提供"撤销"按钮（5 秒内可点）。
退出多选 ① 点取消；② ESC 键；③ 操作完成自动退出。退出后 checkbox 全部隐藏。
需求 06

资产详情与关联推荐

消费阵地
用户点击单条资产后，右侧滑出详情面板。详情面板承担深度消费 + 关联探索 + AI 处理三件事 —— 这是 AI 收藏夹"资产飞轮"的核心场景。
功能点逻辑说明
触发详情面板 用户单击主内容区任一卡片 → 右侧详情面板从右侧滑入（占屏 30%-40%），主内容区不消失（仍可继续点别的卡片切换）。
详情面板顶栏 ① 资产标题；② 类型徽章；③ 来源；④ 操作按钮（加星 / 问 AI / 编辑标签 / 删除 / 在新标签打开）；⑤ 关闭按钮。
详情主体内容 按资产类型展示对应主体（见需求 04各类卡片的"点击后详情"）：网页 → 摘要 + 正文锚点；图片 → 大图 + OCR；文档 → 内嵌查看器；摘录 → 全文 + 回原文按钮；AI 对话 → 完整 QA。
详情区放大态 详情面板顶部一个"放大"按钮 → 详情区扩展至 70% 宽度，左侧导航折叠不消失（保持上下文）。再点恢复正常宽度。
关联推荐区 详情主体下方一块"关联推荐"区，展示与当前资产相关的已收藏过的资产（向量相似 + 同标签 + 同来源）。不引入全网新内容（避免变 feed 流）。
关联推荐开关 D3 待决策：是否给推荐区一个折叠 / 关闭按钮。倾向：默认展开 + 折叠按钮。用户偏好持久化。
主题模式 详情面板可切到主题模式 —— 围绕当前资产，展开同主题相关的所有资产（图谱式聚合视图），适合"研究某个话题"的深度场景。
标签编辑 详情区可点击标签 → 编辑 / 删除；可新增标签（自动联想已有 + 输入新建）。
退出详情 ① 点关闭按钮；② 再次单击同一卡片；③ ESC 键。退出时面板向右滑出。
需求 07

AI 助手对话面板

元宝承接
AI 收藏夹不自造 AI 能力 —— 所有 AI 调用走元宝助手承接。右侧 AI 面板 = 元宝助手的内嵌入口，可基于资产做问答 / 总结 / 对比 / 生成。
功能点逻辑说明
触发 AI 面板 ① 顶部栏右侧"AI 助手"图标；② 卡片快捷操作"问 AI"；③ 多选后批量"问 AI"；④ 详情面板"问元宝"按钮。任一触发 → 右侧 AI 面板滑入。
AI 面板与详情面板关系 互斥 / 二选一。同一时刻右侧只展示其中一个。从详情切到 AI 时，详情自动收起；反之亦然。
对话主体 标准对话流（QA pair）+ 输入框。所有交互沿用元宝助手现有规范（不另起一套）。
上下文绑定（核心差异化） 用户从某资产 / 多选资产触发的对话，该批资产自动作为对话 context，AI 面板顶部以小卡片形式展示已绑定的 context（"基于这 3 项资产"），可点 X 移除单个。
AI 引用 Source AI 回答中如果引用了 AI 收藏夹的资产，回答中以角标 [1] [2] 形式标注，鼠标 hover 显示来源摘要，点击跳转到主内容区高亮该资产。
反向调用 用户在元宝助手主入口（不是 AI 收藏夹内）问"我之前收藏的 XX" → 元宝自动从 AI 收藏夹检索 + 引用资产作答（即 AI 收藏夹 = 元宝的记忆库）。
对话历史 AI 面板支持查看历史对话（按时间倒序），可继续接历史对话提问。
退出 AI 面板 ① 关闭按钮；② 切到详情面板；③ ESC 键。
需求 08

元宝对话沉淀链路

独占差异化
用户在元宝助手里产生的优质对话 → 一键沉淀回 AI 收藏夹的「AI 对话」Tab，永久保留 + 嵌套资产自动分流。
功能点逻辑说明
沉淀入口 元宝助手单条对话右上角加「沉淀此对话」按钮（由 Geoffrey 在元宝助手侧自己提单加，不依赖元宝团队排期）。
沉淀确认弹窗 用户点按钮 → 弹出小确认窗：① 对话标题（默认用首句问题，可改）；② 标签（自动推荐 + 可改）；③ "沉淀"主按钮 / "取消"。
沉淀主对话 主对话（QA pair + AI 引用的 URL 列表 + 工具调用记录）入「AI 对话」Tab，作为永久副本，与元宝侧原对话完全独立。
嵌套资产自动分流 对话里嵌套的资产自动分流到对应 Tab：
① 用户上传 / AI 引用的图片 → 图片 Tab；
② 用户上传 / AI 生成的文档（PPT / Word / 长文档）→ 文档 Tab；
③ AI 引用的网页 URL → 网页书签 Tab。
每条嵌套资产自动加标签"来自 X 月 X 日的元宝对话"，可点击回跳主对话。
独立性保证 元宝侧删除原对话 / 修改原对话 / 分享链接失效 → AI 收藏夹副本不受影响（沉淀 = 永久副本）。
反向：AI 收藏夹删对话 用户在 AI 收藏夹内删除已沉淀的对话 → 仅删 AI 收藏夹副本 + 解除嵌套资产关联。元宝侧原对话不动。
边界规则 ① 单对话 ≤ 100K token；② 嵌套图 ≤ 5 / 嵌套文档 ≤ 3；③ 单嵌套文件 > 50MB → 提示"建议存到小云盘后再沉淀"；④ 总对话数 ≤ 500 条。
常用 Prompt 库 「AI 对话」Tab 第二区域 = 用户常用 Prompt 库，支持收藏 / 分类 / 一键填充到元宝。上限 200 条。

设置中心

用户偏好
