战略对齐

为什么这件事必须现在做

0.4 主战场 · 大目标

2026 H2 浏览器核心命题：从"看网页的工具"升级为"承接用户记忆与行为的 AI 入口"。AI 资产专项是这个升级的核心载体。

AI 收藏夹的战略价值 · 三层

📍 近期

补齐浏览器"用户主动留痕"的能力空白，提升 PC 端 DAU 与停留时长。

🌟 中期

成为浏览器与元宝助手的共享记忆中枢——浏览器贡献场景化资产，元宝消费这些资产做个性化。

🚀 长期

在 Agent 时代抢占"用户记忆入口"——用户的工作流上下文 = 浏览器拥有 = AI 时代的核心资产。

用户场景洞察 & 核心痛点

基于 QB 历史调研 + 0618 用户行为分析

PC 端用户三大场景分布（约 90%）

场景典型行为资产沉淀痛点
信息收集看资讯、查资料、做研究、追内容临时收藏太多 / 找不回来 / 用不起来
资源获取下视频、下文件、找模板下载完散落各处，复用率低
文件 & 事务处理看文档、写报告、做表格跨工作流的文件 / 网页 / 对话无法关联

阶段性资产 · 4 大痛点

  • ❌ 不想全存书签：怕积累冗余、编辑成本高、找不回来
  • ❌ 但又怕丢失上下文：关闭浏览器/切换设备就忘了"我刚才在干嘛"
  • ❌ 用户主动收藏后，AI 用不起来：收藏只是"存"，没有"用"的闭环
  • ❌ 多模态资产无处放：网页、文件、图片、AI 对话各自孤立

4 个真实场景案例

📌 场景 A · 买车决策
用户花两周对比 5 款车：30+ 网页 + 视频测评 + 元宝聊过对比 + 报价单 PDF —— 这些资产现在散落 4 个地方，决策时根本拼不起来。
📚 场景 B · 学习资料
学生收集"机器学习入门"：知乎 + GitHub + B 站 + PDF 论文 + 元宝笔记 —— 下次复习要去 4 个入口翻找。AI 收藏夹 = 一站式资产箱。
💼 场景 C · 跨端汇报
白天公司 PC 整理"行业研究"，晚上回家用手机继续 —— 书签同步可以，但行为层资产（停留时长 / AI 对话 / 批注）丢失。
🛍️ 场景 D · 临时清单
用户买年货：30 商品页 + 比价截图 + 评测 —— 不想存书签污染收藏夹，又想保留到买完为止。AI 收藏夹 = 短周期临存。

用户分层（按使用强度）· 黄金中度是核心目标

层占比使用模式对 AI 收藏夹的需求
轻度~58%每月收藏 1-10 条低 → 主要是"快存" + 减少认知负担
黄金中度 ⭐~37%11-100 条，有手动分类核心目标用户 → AI 整理 + 多模态收纳 + 元宝调用
重度~5%100+ 条，文件夹层级深极高 → 智能整理 + 资产搜索 + 跨设备同步

三件套 · 快存 + 智能整理 + 元宝调用

从输入到处理到价值兑现

📥 快存悬浮球（轻量化留痕）

触发
  • 常驻：浏览器右下角（可调）
  • 快捷键：Win Ctrl+Space / Mac Cmd+Enter
  • 拖拽：拖文字/图/链/文件即存（默认 0s）
7 种存储方式
  • 拖拽 / 右键菜单 / 划词收藏
  • 截图 / 本地上传 / 地址栏 ⭐
  • 元宝对话沉淀

🤖 智能整理（书签 Tab · 已与 vance 链路打通）

  1. 用户勾选要整理的书签范围（base 文件夹）
  2. 已抽取的网页内容 → 模型 → tag_list（智能打标）
  3. tag_list + 用户 path 偏好 → 启发式分组（base 之下最多 4 层 = L1~L4）
  4. 预览结果 → 用户确认 → 落地
约束：默认预览（不直接覆盖）+ 30 天回收兜底 + 单次上限 1000 条 + 用户原结构尊重（一期不做，二期接 path 复用）

💬 AI 能力 · 全部走元宝助手

不自造 AI 能力 —— AI 收藏夹只负责"准备好资产"，AI 调用全部交给元宝。

  • 右键单条 → "问元宝" / "总结" / "做 PPT"
  • 多选 + 右键 → "对比 / 合并问元宝"
  • 整组资产 → "整组发给元宝分析"
  • 反向：元宝问"我之前收藏的洗碗机对比" → 自动调出收藏夹相关资产
